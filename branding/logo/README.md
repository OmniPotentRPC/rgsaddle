# rgsaddle branding

Same LODE indigo / amber family as rgmin, landfold, and
readcon-core. The geometry is a col.

**rgsaddle** is band, min-mode, and IRC mechanics over rgmin
steppers. It defines no optimizer of its own.

## Concept

- **Ridge** -- the NEB band sitting on the surface.
- **Amber path** -- both downhill branches of the IRC, meeting
  at the col.
- **Gold disk** -- the first-order saddle / climbing image.
- **Palette** -- indigo / violet (`#1E1B4B`, `#312E81`, `#4F46E5`)
  + amber (`#FBBF24`, `#F59E0B`).

The wordmark does not name eindir.
