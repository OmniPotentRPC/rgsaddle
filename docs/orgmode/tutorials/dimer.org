#+TITLE: Find a saddle with the dimer
#+OPTIONS: toc:nil num:nil

A minimum-mode search estimates the lowest curvature direction, reflects the force along it, and takes one solver step. The host owns the loop. This page is the dimer. Lanczos is the same session with ~MinModeKind::Lanczos~.

The double well \(V = (x^2 - 1)^2 + 2y^2 + 2z^2\) has a saddle at the origin. The runnable form is the example on ~MinModeSession~ in the crate docs, and ~examples/double_well.rs~ is the band on the same surface. From Python, ~rgsaddle.ase.MinModeAtoms~ is the ASE-shaped call:

#+begin_src python
from ase import Atoms
from rgsaddle.ase import MinModeAtoms

atoms = Atoms("H", positions=[[0.4, 0.3, 0.0]])
atoms.calc = bowl  # energy 2 x^2 + 5 y^2
search = MinModeAtoms(atoms, mode=[1.0, 0.0, 0.0], kind="dimer")
forces = search.get_forces()
#+end_src

Above the well the curvature is positive, so the returned force lies along the mode and the perpendicular part is dropped. ~tests/python/test_ase_dropin.py~ checks that on this bowl. Once the curvature is negative the force along the mode is reflected and the perpendicular force stays, which is the translation Henkelman and Jónsson use to leave a minimum toward a saddle.

The stepper is an rgmin method on that effective force. FIRE is the default. L-BFGS takes one step per call because the reflected force is not the gradient of the energy the surface reports. ~MinModeConfig.seed_curvature~ scales only the first empty translation by \(1/|\lambda|\).

Lanczos builds a Krylov subspace of finite-difference Hessian actions and stops on the residual. Set ~kind="lanczos"~ on the Python object, or ~MinModeKind::Lanczos~ on the Rust config. The same ~get_forces~ contract holds.
