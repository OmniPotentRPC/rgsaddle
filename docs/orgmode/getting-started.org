#+title: Getting started
#+options: toc:nil num:nil author:nil

A host builds a band and steps it until the projected force is under =force_tol=. The host owns the loop, not this crate.

* 1. Depend on the published crate
#+begin_src toml
[dependencies]
rgsaddle = "0.4.0"
ndarray = "0.17"
#+end_src

* 2. Implement =BandSurface=
One =eval= fills the energies and gradients of the rows it receives. The first call gets the whole band. Later calls get the interior images: the endpoints never move, so the session keeps their energies.
The double well \(V = (x^2 - 1)^2 + 2y^2 + 2z^2\) has minima at \((\pm 1, 0, 0)\) and a saddle at the origin with energy 1:

* 3. Step
Nine images run from one minimum to the other, bowed off the path so the band has work to do.
The host calls =step= until the band reports =Converged=:

#+INCLUDE: "../../examples/double_well.rs" src rust :lines "39-61"

The default stepper is FIRE 2.0, the fast inertial relaxation engine of Guénolé, Nöhring, Vaid, Houllé, Xie, Prakash and Bitzek, Comput. Mater. Sci. 175, 109584 (2020), doi:10.1016/j.commatsci.2020.109584.
eOn's FIRE is the original method of Bitzek, Koskinen, Gähler, Moseler and Gumbsch, Phys. Rev. Lett. 97, 170201 (2006), doi:10.1103/PhysRevLett.97.170201.
L-BFGS runs under rgmin's =Accept::Step=: the projected band force is not conservative, so a step is taken without an energy test.
The climbing image is that of Henkelman, Uberuaga and Jónsson, J. Chem. Phys. 113, 9901 (2000), doi:10.1063/1.1329672.

* 4. Run it
The code above is =examples/double_well.rs=.
From the repository root:

#+begin_src console
$ cargo run --example double_well
#+end_src

#+begin_example
Converged after 8 steps, max force 2.8e-4
climbing image 4 at (0.0000, 0.0001, 0.0000), energy 1.000000
#+end_example

The climbing image is image 4, the middle of the nine.
It sits on the saddle at the origin, and its energy is the barrier.

* 5. Reset when the surface changes
=BandSession::reset= is the model-update boundary.
Quasi-Newton history taken on one surface epoch must not survive onto the next.
