#+TITLE: PAFI types
#+OPTIONS: toc:nil num:nil author:nil

Full API documentation for every item below is on [[https://docs.rs/rgsaddle][docs.rs/rgsaddle]], under =rgsaddle::pafi=; =cargo doc --open= builds the same pages from a checkout. This page is the inventory: every public configuration and result type the module exports, and the functions that connect them. =tutorials/pafi= walks through using them; =explanation/pafi-ohtst= has the theory.

* Path types
| Type | Role |
|------+------|
| =ArcPath= | A cubic-spline path through ordered frames. =from_positions= builds it from a list of Cartesian configurations, reactant first, parameterized by the summed chord lengths from the first; =new= takes frames with a parameter of the caller's; =reversed= is the same curve run from the other end; =bounds= gives the parameter of the first and last frame, =arcs= every frame's parameter, and =geometry(arc)= the position, tangent, curvature and jerk of the spline at a parameter inside =bounds=, and =SaddleError::Invalid= outside them |
| =PathFrame= | One frame of a path: =positions= (the Cartesian configuration) and =arc= (its path parameter; the chord length from the first frame for =from_positions=) |
| =PathGeometry= | =positions= (=X(s)=), =tangent= (=X'=), =curvature= (=X''=), =jerk= (=X'''=, constant on each spline segment) and =arc= (=s=) at one point along a path |
| =FramePlanes= | One plane through every path frame: unit =normals=, their =curvatures=, the frame =arcs= and the ascending =active= atom indices. =ArcPath::frame_planes= uses the full frame tangent and =ArcPath::truncated_planes= restricts it to the leading share of atoms |

* Sampling configuration and results
| Type | Role |
|------+------|
| =PafiConfig= | Non-exhaustive; chain =with_*= setters from =default=. Defaults: =thermal = 0.02585= (300 K in eV), =mobility = 1.0=, =time_step = 1e-3=, =integrator = PafiIntegrator::LeimkuhlerMatthews=, =mean_force = PafiMeanForce::ReferenceCode=, =thermalize = 200=, =stride = 5=, =samples = 200=, =blocks = 5=, =trajectories = 1=, =seed = 1=, =fix_com = true=, =retain = 16=, =target_error = None=, =max_rounds = 4=, =region = None=, =max_jump = Some(0.4)=, =quench = RelaxConfig::default().with_method(Method::Ode12r)=, =relax_tol = 1e-6=, =jump_tol = 1e-3= and =window = 16=. =thermal= is =kT= in the surface's energy unit; =mobility= and =time_step= set the overdamped Langevin step; =integrator= picks =PafiIntegrator= (also exported as =Integrator=) and =mean_force= picks =PafiMeanForce=; =thermalize= is the minimum warm-up before the automated equilibration test, =stride=, =samples= and =blocks= control the production run and its block standard error, and =trajectories= runs that many independent trajectories per plane; =seed= fixes the noise stream; =fix_com= removes the mean Cartesian drift on systems with at least two atoms; =retain= keeps that many evenly spaced recorded configurations on each plane for later reuse; =region= restricts the walk to a hard =Region=; =max_jump= and =quench= (a =RelaxConfig=) reject a stretch of the walk whose in-plane minimum has moved more than =max_jump= from the path's own, so the walk stays in the basin of the path; =relax_tol= controls the force tolerance when frame planes are relaxed before sampling, and =jump_tol= and =window= control the windowed jump test; =target_error= and =max_rounds= run extra sampling rounds on every plane, inverse-variance combined with the first, until the barrier error meets the target or the round budget is spent (=howto/pafi-ohtst-restarting=) |
| =PafiIntegrator= | =LeimkuhlerMatthews= (the default, second order for stationary averages) or =EulerMaruyama= (the direct step of the paper's Eq. (9)) |
| =PafiMeanForce= | =ReferenceCode= (the default: the first term of the paper's Eq. (8), as LAMMPS =fix pafi= averages it) or =PublishedEquation8= (both terms, the second being =kT d/ds ln(|psi| / |X'|)=) |
| =HyperplaneAverage= | One plane's result: =gradient= (=dF/ds=), its =error=, the mean =psi= (the correction term, zero on a straight path), =samples= recorded (summed over rounds), the integrated autocorrelation time =tau= in samples, =n_eff= (=(samples - discard) / (2 tau)=), total force =evaluations=, the =retained= configurations on the plane, the =equilibration= report and the number of stretches =rejected= for leaving the basin (=howto/pafi-ohtst-checking-convergence= covers reading =tau= and =n_eff=) |
| =FreeEnergyProfile= | The potential of mean force integrated from the first plane: per-plane =arc=, =gradient= and =gradient_error=, the trapezoid-integrated =free_energy= and its propagated =free_energy_error=, the =barrier= (the profile's maximum, with the reactant held at zero) and its =barrier_error=, the index of that maximum in =dividing=, and total recorded =samples= across every plane and round |
| =BalancedBarriers= | Forward and reverse barriers constrained to differ by a known end-state free-energy gap, their shared =error= and the profile-integration =drift=. =balanced_barriers= inverse-variance combines both readings and =anchored_barriers= keeps the forward reading; =FreeEnergyProfile::balanced= and =FreeEnergyProfile::anchored= apply them to a profile |

* Functions
| Function | Role |
|----------+------|
| =average_hyperplane= | Samples one hyperplane by overdamped Langevin dynamics restricted to the plane, with =PafiConfig::trajectories= trajectories, and returns its =HyperplaneAverage= |
| =average_hyperplane_with_sampler= | The same estimator over any =HyperplaneSampler=, such as a molecular-dynamics engine |
| =pafi_profile= | Samples every arc length in parallel on rayon's global thread pool and integrates to a =FreeEnergyProfile=, returning it alongside every plane's =HyperplaneAverage=; runs extra rounds when =PafiConfig::target_error= is set |
| =pafi_frames= | Relaxes and samples one plane through every frame using the full frame tangent |
| =pafi_truncated= | Relaxes and samples those frame planes after restricting each normal to the leading share of atoms |
| =flat_hyperplane_gradient= | Evaluates the flat-plane free-energy derivative from a potential gradient, displacement, unit normal, normal derivative and path tangent |
| =harmonic_mask_shift= | Maps a masked-plane barrier to another normal from the reactant and dividing-plane harmonic compliances |
| =integrate_profile= | Trapezoid-integrates a set of arc lengths, gradients and their errors directly, with no sampling, into a =FreeEnergyProfile= |
| =zero_temperature_barrier= | Integrates the potential's own gradient along a path with no sampling (=PafiConfig::thermal= plays no part): a check of the path itself, exact on a converged minimum-energy path |
| =attempt_frequency= | Not part of =rgsaddle::pafi= itself (it is exported from =rgsaddle::defect_pair=), but the usual prefactor for turning a PAFI barrier into a rate: =nu = angular * sqrt(lambda / mass) / (2 pi)= from a curvature =lambda= along the path tangent at the reactant. =rgsaddle::arrhenius= (from =rgsaddle::strain_rate=, fixed to eV and kelvin) is the wrong call for a reduced-units surface; multiply =nu= by =exp(-barrier / kT)= directly instead, as =tutorials/pafi= does |

* What the tests check
=tests/pafi_analytic.rs= checks the sampled profile on a one-dimensional barrier and on a two-dimensional well with a known transverse free-energy shift, against the closed form the shift gives. =examples/pafi_tutorial.rs= runs the same kind of check, on a different surface, with numbers printed rather than asserted; =tutorials/pafi= walks through it.
