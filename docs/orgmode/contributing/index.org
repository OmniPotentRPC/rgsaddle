#+OPTIONS: toc:nil num:nil

Build and test a pinned checkout with its Cargo lockfile. The C and C++ smoke tests require the C ABI library as well as the test executables.

#+begin_src sh
cargo build --locked --features capi
cargo test --locked --features capi
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo fmt --check
#+end_src

Optional features are checked with their dependencies enabled. Build the Python wheel with maturin and run ~tests/python~ against the installed wheel. The algebra and interval checks live in ~validation~ and ~tests/symbolic~; the Lean libraries live in ~formal~.

Narrative additions use the Org sources under ~docs/orgmode~ and matching reStructuredText files under ~docs/source~. ~docs/export.el~ exports the nested guides and changelog. Sphinx reads the generated tree. Retain numerical assertions and record the source, dependency and library revisions with performance results.
