The dimer translation and the climbing image are one Householder reflection of the true force. Goswami, Gunde, and Jónsson, Front. Chem. (2026), doi:10.3389/fchem.2026.1807063, Eqs. 3, 8, and 9, and Sec. 2.3.1 and Sec. 4. The dimer is that reflection on a three-image chain with free ends. Goswami (2026), arXiv:2603.10992, doi:10.48550/arXiv.2603.10992, Eqs. 2.14-2.16.

A preset chooses the sides, the tangent, the coupling, the climb, and the mesh. =Stencil::point= runs a minimiser, the dimer, Lanczos, ART, and eigen following. Dimer and Lanczos construct =MinModeSession=, so the recorded position and energy hashes stay the same. =Stencil::band= names the band presets and returns the =feat/band-methods-zoom= seam. Zoom, the recomputed energy-weighted spring, and the band keys are that branch.

| Preset | Tangent | Climb | Mode |
|--------+---------+-------+------|
| minimiser | none | none | none |
| dimer | axis | reflect if the curvature is negative, otherwise ascend | rotation |
| Lanczos | Ritz | as the dimer | Lanczos |
| ART | seed, then Ritz | ascend until the curvature drops, then reflect | Lanczos |
| eigen following | lowest eigenvector | as the dimer | dense central-difference =exact_eigh= |

rgmin started as Rohit Goswami's xtsci-optimize (2023-2024), which composed minimisers from small strategy objects. The stencil core extends that to saddle and band methods. eOn v2.9.0.1 is doi:10.5281/zenodo.18529495. Goswami (2025), arXiv:2510.21368, doi:10.48550/arXiv.2510.21368.

=Chain::evaluate= owns one block per image. The block size is fixed at one image and does not depend on the thread count. Each block is written back by index after the surface call. Remesh, insert, and window do not call the surface. Image ids survive an insert.

The C surface is =rgsaddle_stencil_*= with an opaque config, typed key setters, and a thread-local =rgsaddle_last_error=. =include/rgsaddle/stencil.hpp= is the RAII wrapper. Python =rgsaddle.Stencil.point= and =rgsaddle.ase.Point= call that wrapper. =Point.run= uses an ASE =Optimizer= subclass. The extension is nanobind with =Py_MOD_GIL_NOT_USED= on a free-threaded build.
