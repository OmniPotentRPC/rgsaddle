#+TITLE: Dense symmetric eigensolver
#+OPTIONS: toc:nil num:nil

~eigh~ copies the symmetric part of its argument, reduces that matrix to bandwidth 64 with tiled Householder panels, chases the bulge to tridiagonal form, and solves the factor with Cuppen's method. The panel reduction is the two-stage algorithm of Haidar, Ltaief, and Dongarra (https://doi.org/10.1145/2063384.2063394). The chase stores a compact band of half-width 128, which holds the fill, and applies each reflector inside that band. The tridiagonal spectrum is Cuppen's divide-and-conquer (https://doi.org/10.1007/BF01396757) as implemented by Gu and Eisenstat (https://doi.org/10.1137/S0895479892241287). Francis QR (https://doi.org/10.1093/comjnl/4.4.332) is the step below faer's recursion threshold. ~partial_eigh~ bisects the same factor and runs inverse iteration for the lowest k pairs. ~k~ equal to the dimension calls ~eigh~.

Every trailing update and the eigenvector product go through ~tile_gemm~. An Ozaki-II kernel can replace that function later. Tile ownership and the faer task count depend on the dimension and on the tile size. They do not read the rayon pool. Feature ~par~ runs those tiles on the pool. Without ~par~ the same partition runs on one thread, and the bits match. The tridiagonal solve uses ~Par::rayon~ with a task count that is a power of two, at most 32, and at least 2 once the dimension reaches 256. Below faer's recursion threshold of 128 the tridiagonal solve is sequential.

Eigenvalues ascend. Each column is signed so that its lowest-index largest-magnitude component is positive. Lanczos ~lowest_ritz~ and ~jacobi_eigen~ call ~partial_eigh~ and ~eigh~.

The tables are medians of 7 interleaved runs. The range is the maximum minus the minimum. Efficiency is the one-thread median divided by the product of the thread count and that count's median. The host is an 8-core Intel Xeon with one thread per core and AVX-512. The default build uses the AVX2 kernels.

The back-transformation scales. Its 8-thread efficiency against its own one-thread time is 0.971. The bulge chase stays near 0.83 s. The band reduction moves from 1.305 s to 0.952 s. Those two flat pieces set the 8-thread efficiency. E(8) is 0.623.

faer's sequential self-adjoint solver, ~Par::Seq~, takes 3.397 s (range 0.273). The one-thread fixed partition is 8.4 times that. The extra cost is the panel reduction and the reflector back-transformation.

Counts are ~cargo tree -e normal --prefix none -p rgsaddle~, unique crate names. Optional dependencies stay in the lockfile either way. The count that matters is the crates a build compiles.

The default build compiles 39 more rows than a build with no default features. That difference is faer and its dependencies. ~eindir-core~ already depends on rayon, so a default build is not free of that crate. Feature ~par~ turns on ~faer/rayon~ and ~rgmin/par~, which is why the no-default build with ~par~ reaches 96 rows.

* Instruction sets

Feature ~eigh-portable~ is on by default. It compiles pulp and gemm at x86-v3 (AVX2) and leaves x86-v4 out. That build is the cross-node invariant mode. Feature ~eigh-avx512~ passes faer's ~nightly~ feature, which compiles the x86-v4 kernels. pulp then selects AVX-512 when the host has it. There is no in-process switch, so the comparison is two release builds of ~eigh_fingerprint_is_stable_inside_one_build~.

The 48 by 48 fingerprint is ~0x7686bb1a1f04ae7a~ in both builds. The 256 by 256 fingerprint is ~0xa361752612971a6d~ in the portable build and ~0xc66540129e6c38e7~ with ~eigh-avx512~. The test pins the portable hashes. A wider build is not required to match them. ~RAYON_NUM_THREADS=1~ and ~RAYON_NUM_THREADS=8~ print the same 48 by 48 hash.
