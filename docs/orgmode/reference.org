* C ABI (feature =capi=)
=include/rgsaddle.h=. =RGSADDLE_ABI_MAJOR= is 1. Status codes include =RGSADDLE_OK=, =RGSADDLE_SHAPE=, =RGSADDLE_SURFACE_FAILED=, =RGSADDLE_ABI_MISMATCH=. Methods on the wire: FIRE, L-BFGS, and quick-min. Min-mode kinds: dimer and Lanczos. Index-1 entries: =rgsaddle_nichols_step=, =rgsaddle_prfo_step=, =rgsaddle_hessian_powell=, =rgsaddle_hessian_bofill=, =rgsaddle_cap_max_abs=, and =rgsaddle_index1_step=. Band cache entries: =rgsaddle_band_restart=, =rgsaddle_band_evaluation= (=RGSADDLE_NO_EVALUATION= when nothing is cached at the current band). Min-mode reuse: =rgsaddle_minmode_set_position=, =rgsaddle_minmode_set_mode=, =rgsaddle_minmode_estimate=; =rgsaddle_minmode_config_t.difference= picks =RGSADDLE_DIFFERENCE_FORWARD= or =_CENTRAL=, and =rotation_angle_tol= stops a dimer rotation whose optimal angle falls under it (radians, 0 off). Both fields are read only from a config whose version minor is 5 or newer. =RGSADDLE_ABI_MINOR= is 16. =RGSADDLE_METHOD_QUICKMIN= runs quick-min on the band. A min-mode session returns null for that code. =rgsaddle_band_create_solid= and =rgsaddle_band_set_stress= carry the solid-state cell block. The report's =evaluations= field took the place of =reserved= at minor 5. =cargo cinstall= installs =include/rgsaddle.h= as written.

* Python package
The importable package is =rgsaddle=. =rgsaddle._core= is the nanobind extension. =import rgsaddle= does not import ASE.

| Name | Role |
|------+------|
| =ForceGate=, =HessUpdate=, =IrcKind=, =MinModeKind=, =EigenDevice=, =ExpandKind=, =CellChart=, =RestrictedKind= | =enum.IntEnum= controls. Names and values match the previous module |
| =NumericalError= | =ArithmeticError= for =RGSADDLE_NON_FINITE= |

| =raise_status= | Map an =rgsaddle_status_t= value. The message is the stored text, or the status name when that text is empty. =RGSADDLE_OK= returns true |

| =rgsaddle.Stencil= | Point search. =point=, =step=, =run=, =positions=, =mode=, =curvature=. =band= raises =ValueError= with the zoom seam |
| =rgsaddle.ase.Point= | ASE =Optimizer= driver for one point preset. =run(fmax, steps)= is ASE's own loop |

=SurfaceAdapter= keeps =get_forces(apply_constraint=False)= on =raw_forces=. The returned gradient is minus =get_forces()= after constraints. The adapter evaluates the given rows in order on the calling thread. =owners()= and =reentrant()= are what a driver uses to group. A second call while the first holds the adapter raises =RuntimeError=.

* Tests that pin the contract
- =tests/double_well.rs= — band finds the origin saddle, endpoints pinned
- =tests/autoneb.rs= — ASE AutoNEB decisions and the Müller-Brown insertion sequence. =tests/autoneb_gate.rs= hashes the insertion list and the trajectory at 1, 2, 3 and 8 threads, and an ignored release run compares AutoNEB with CI-NEB at one force-call budget. Strong scaling of a full AutoNEB run is an ignored test in the crate.
- =tests/minmode_saddle.rs= — dimer / Lanczos
- =tests/nichols_saddle.rs= — Nichols step against i-PI on the same Hessian and gradient, Muller-Brown saddles, quadratic saddle
- =tests/prfo_saddle.rs= — partitioned RFO against the augmented Hessian, trust sphere changes the mode ratio
- =tests/c_abi.rs= — header and symbols with =capi=
- =validation/= — sympy and sollya checks of the dimer rotation, the Lanczos residual bound, and the finite-difference curvature
