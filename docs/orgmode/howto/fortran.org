#+TITLE: Use the Fortran bindings
#+OPTIONS: toc:nil num:nil

The optional Fortran layer is a Fortran 2008 module, =rgsaddle=, built on top of =include/rgsaddle.h= with =iso_c_binding=. The feature is off by default. Enable it in meson with:

#+begin_src sh
meson setup build -Dfortran=enabled
meson compile -C build
meson install -C build
#+end_src

The install has:

- =librgsaddle_fortran=, the wrapper library
- =rgsaddle.mod= under =include/rgsaddle/fortran=
- =rgsaddle-fortran.pc=
- CMake package files under =lib/cmake/rgsaddleFortran=

The module exports typed handles with finalizers for:

- climbing-image band sessions (NEB)
- minimum-mode sessions (dimer and Lanczos)
- projected average force integration (PAFI)
- optimal-hyperplane transition-state theory (OH-TST)

Surface callbacks are available in two forms:

1. A native Fortran callback, =surface_proc=, that receives positions, energies and gradients in image-major order.
2. A raw C callback path (=step_c=) that takes a =c_funptr= to an existing C-compatible callback.

Both routes call the same Rust C ABI and are checked against each other by the Fortran tests.

* Minimal loop
1. Fill and stamp =rgsaddle_band_config_t= with =init_band_config=.
2. Create a =band_handle= with =create=.
3. Call =step= (Fortran callback) or =step_c= (C callback) until =report%status= is =RGSADDLE_STATUS_CONVERGED=.
4. Read back rows with =positions=.
5. Let scope exit free the handle through the finalizer.

Minimum-mode uses the same pattern through =rgsaddle_minmode_config_t= and =minmode_handle=.

* PAFI on an analytic one-dimensional barrier
PAFI takes a point callback, =point_surface_proc=, over one geometry:

#+begin_src fortran
type(pafi_handle) :: pafi
type(rgsaddle_pafi_config_t) :: cfg
type(rgsaddle_pafi_result_t) :: out
real(c_double) :: frames(41), arcs(41)
integer(c_int) :: status
procedure(point_surface_proc), pointer :: cb

call init_pafi_config(cfg)
cfg%thermal = 0.02_c_double
cfg%samples = 4_c_int64_t
cfg%blocks = 2_c_int64_t
cfg%seed = 3_c_int64_t
! Fill frames/arcs for x in [-1, 1].
status = pafi%create(cfg, 41_c_int64_t, 1_c_int64_t, frames, arcs)
cb => my_point_surface
status = pafi%run(cb, c_null_ptr)
status = pafi%result(out)
#+end_src

The profile arrays come from =pafi%profile(...)= (arc, gradient, gradient error, free energy, free-energy error).

* OH-TST on a quadratic saddle
OH-TST also takes a point callback and exposes the transmission summary and curve:

#+begin_src fortran
type(ohtst_handle) :: tx
type(rgsaddle_ohtst_config_t) :: cfg
type(rgsaddle_ohtst_result_t) :: out
real(c_double) :: point(2), normal(2), t(32), kappa_t(32)
integer(c_int64_t) :: written
integer(c_int) :: status
procedure(point_surface_proc), pointer :: cb

call init_ohtst_config(cfg)
cfg%thermal = 0.5_c_double
cfg%shooting_friction = 1.5_c_double
cfg%shooting_shots = 4096_c_int64_t
point = [0.0_c_double, 0.0_c_double]
normal = [1.0_c_double, 0.0_c_double]
status = tx%create(cfg, 2_c_int64_t, point, normal)
cb => my_point_surface
status = tx%run(cb, c_null_ptr)
status = tx%result(out)
status = tx%curve(t, kappa_t, written)
#+end_src

These are exercised in =tests/fortran/test_pafi.f90= and =tests/fortran/test_ohtst.f90= on the same analytic surfaces as the Rust OH-TST and PAFI tests.
