#+TITLE: Use the Fortran bindings
#+OPTIONS: toc:nil num:nil

The optional Fortran layer is a Fortran 2008 module, =rgsaddle=, built on top of =include/rgsaddle.h= with =iso_c_binding=. The feature is off by default. Enable it in meson with:

#+begin_src sh
meson setup build -Dfortran=enabled
meson compile -C build
meson install -C build
#+end_src

The install has:

- =librgsaddle_fortran=, the wrapper library
- =rgsaddle.mod= under =include/rgsaddle/fortran=
- =rgsaddle-fortran.pc=, which also names =-lrgsaddle=
- CMake package files under =lib/cmake/rgsaddleFortran= (or =<libdir>/cmake/rgsaddleFortran=)

=librgsaddle= itself is the cargo cdylib (=cargo build --features capi= or =cargo cinstall=). The pkg-config and CMake files name it, and the link still needs the directory that holds it, for example =-Ltarget/debug -Wl,-rpath,target/debug= before the pkg-config libraries. The CMake imported target =rgsaddle::fortran= links =librgsaddle= when =find_library= locates it, or when =rgsaddleFortran_CAPI_LIBRARY= is set. The package paths are relative to the config file, so the prefix can be moved.

The module binds a subset of the C ABI: band create, step, and positions; minimum-mode create, step, position, and mode; and the PAFI and OH-TST create, set-config, run, result, and profile or curve calls. It does not bind set-positions, reset, estimate, connect, index-k, Sella, or the solid-state band. Status codes and the method, minimum-mode, OH-TST, band-per-image, and one-image constants used by those calls are exported. The rest of the C enums (tangent, spring, projection, difference, RTR, quick-min, LOBPCG) are not; pass the integer values from =rgsaddle.h=.

The module exports typed handles with finalizers for:

- climbing-image band sessions (NEB)
- minimum-mode sessions (dimer and Lanczos)
- projected average force integration (PAFI)
- optimal-hyperplane transition-state theory (OH-TST)

A handle is not copyable. =b = a= stops the program with status =RGSADDLE_HANDLE_NOT_ASSIGNABLE= (17), because both finalizers would free the same session. =call b%move_from(a)= transfers the session and leaves =a= null. =call a%release()= frees it before the finalizer would. The finalizer runs when the handle goes out of scope in a procedure; a main-program variable may not be finalized.

Surface callbacks are available in two forms:

1. A native Fortran callback, =surface_proc= or =point_surface_proc=. The trampoline passes the number of rows that are actually in the buffers. For =RGSADDLE_REQ_ONE_IMAGE= that number is 1 and =image= is the band index; a batch passes =image = -1=.
2. A raw C callback path (=step_c= / =run_c=) that takes a =c_funptr= to an existing C-compatible callback.

The position, energy, and gradient arguments (and =frames= on =pafi_handle%create=) are assumed-size. The caller, and the trampoline, must supply the length the C request describes. A request whose row count does not fit in the default integer returns =RGSADDLE_SHAPE= and does not call the callback. In C, band buffers are row-major =n_images= by =3 * n_atoms= (image stride =3 * n_atoms=) and PAFI frames are row-major =n_frames= by =n_dof= (frame stride =n_dof=). Because Fortran stores arrays in column-major order (the first subscript varies fastest in memory), coordinate dimensions come first and the image or frame dimension comes last, mapping directly onto the C layout without transposing:

#+begin_src fortran
real(c_double) :: band(3, n_atoms, n_images)
real(c_double) :: frames(n_dof, n_frames)

! Atom a of image i occupies three contiguous doubles at band(:, a, i).
band(:, a, i) = [x, y, z]
status = neb%create(bcfg, int(n_images, c_int64_t), int(n_atoms, c_int64_t), band)

! Frame k occupies n_dof contiguous doubles at frames(:, k).
frames(:, k) = q(:)
status = pafi%create(pcfg, int(n_frames, c_int64_t), int(n_dof, c_int64_t), frames)
#+end_src

PAFI and OH-TST call the point callback from worker threads. The procedure must be safe to run concurrently and must be declared =recursive= (gfortran's recursion check treats those calls as re-entrant). The callback and its =user= pointer travel in the C user-context argument for that call. There is no module-level callback, so one run can call back into another.

=init_minmode_config= fills the Rust =MinModeConfig= defaults, including the five-degree rotation-angle stop. =seed=, =sample_seed=, and =shooting_seed= are the bits of the C =uint64_t=. Values above 2^63-1 are negative =integer(c_int64_t)= values; =uint64_bits(high, low)= builds them from the low 32 bits of each argument.

=profile= and =curve= take the array length as the capacity. When the arrays are shorter than the stored series, the call returns =RGSADDLE_INVALID_PARAMETER= and sets the =written= argument to the length that was required. The same contract is on =rgsaddle_pafi_profile= and =rgsaddle_ohtst_curve=. A null =create= keeps =RGSADDLE_ABI_MISMATCH= when the config major is not 1 and =RGSADDLE_SHAPE= when the dimensions are not a session, instead of reporting both as =RGSADDLE_INVALID_PARAMETER=.

Both callback routes call the same Rust C ABI. The Fortran tests check convergence on an analytic surface, not only that the two routes agree.

* Minimal loop
1. Fill and stamp =rgsaddle_band_config_t= with =init_band_config=.
2. Create a =band_handle= with =create=.
3. Call =step= (Fortran callback) or =step_c= (C callback) until =report%status= is =RGSADDLE_STATUS_CONVERGED=.
4. Read back rows with =positions=.
5. Let scope exit free the handle through the finalizer.

Minimum-mode uses the same pattern through =rgsaddle_minmode_config_t= and =minmode_handle=.

* Runnable PAFI and OH-TST example
Both =pafi_handle= and =ohtst_handle= take a =point_surface_proc= callback (or =c_funptr= via =run_c=). Save the following program as =pafi_ohtst_demo.f90=:

#+begin_src fortran
module demo_surfaces
  use, intrinsic :: iso_c_binding
  use rgsaddle, only: RGSADDLE_OK, RGSADDLE_INVALID_PARAMETER
  implicit none
contains
  recursive integer(c_int) function double_well(user, n_dof, position, energy, gradient) result(status)
    type(c_ptr), value :: user
    integer(c_int64_t), value :: n_dof
    real(c_double), intent(in) :: position(*)
    real(c_double), intent(inout) :: energy
    real(c_double), intent(inout) :: gradient(*)
    real(c_double) :: x
    if (n_dof /= 1_c_int64_t) then
      status = RGSADDLE_INVALID_PARAMETER
      return
    end if
    x = position(1)
    energy = (1.0_c_double - x * x) ** 2
    gradient(1) = -4.0_c_double * x * (1.0_c_double - x * x)
    status = RGSADDLE_OK
  end function double_well

  recursive integer(c_int) function quad_saddle(user, n_dof, position, energy, gradient) result(status)
    type(c_ptr), value :: user
    integer(c_int64_t), value :: n_dof
    real(c_double), intent(in) :: position(*)
    real(c_double), intent(inout) :: energy
    real(c_double), intent(inout) :: gradient(*)
    if (n_dof /= 2_c_int64_t) then
      status = RGSADDLE_INVALID_PARAMETER
      return
    end if
    energy = 0.5_c_double * (-position(1) ** 2 + 4.0_c_double * position(2) ** 2)
    gradient(1) = -position(1)
    gradient(2) = 4.0_c_double * position(2)
    status = RGSADDLE_OK
  end function quad_saddle
end module demo_surfaces

program pafi_ohtst_demo
  use, intrinsic :: iso_c_binding
  use rgsaddle
  use demo_surfaces
  implicit none

  integer, parameter :: n_frames = 41
  type(pafi_handle) :: pafi
  type(rgsaddle_pafi_config_t) :: pcfg
  type(rgsaddle_pafi_result_t) :: pout
  real(c_double) :: frames(n_frames), arcs(n_frames)
  real(c_double) :: grad(n_frames), grad_err(n_frames), free_e(n_frames), free_err(n_frames)
  integer(c_int64_t) :: written
  integer(c_int) :: status, i
  procedure(point_surface_proc), pointer :: cb

  type(ohtst_handle) :: tx
  type(rgsaddle_ohtst_config_t) :: ocfg
  type(rgsaddle_ohtst_result_t) :: oout
  real(c_double) :: point(2), normal(2), t(32), kappa_t(32)

  call init_pafi_config(pcfg)
  pcfg%thermal = 0.02_c_double
  pcfg%time_step = 0.01_c_double
  pcfg%thermalize = 5_c_int64_t
  pcfg%stride = 1_c_int64_t
  pcfg%samples = 200_c_int64_t
  pcfg%blocks = 5_c_int64_t
  pcfg%seed = 3_c_int64_t
  pcfg%fix_com = 0_c_int32_t
  pcfg%retain = 1_c_int64_t
  pcfg%max_rounds = 1_c_int64_t

  do i = 1, n_frames
    frames(i) = -1.0_c_double + 2.0_c_double * real(i - 1, c_double) / real(n_frames - 1, c_double)
    arcs(i) = 2.0_c_double * real(i - 1, c_double) / real(n_frames - 1, c_double)
  end do

  status = pafi%create(pcfg, int(n_frames, c_int64_t), 1_c_int64_t, frames, arcs)
  if (status /= RGSADDLE_OK) stop 1
  cb => double_well
  status = pafi%run(cb, c_null_ptr)
  if (status /= RGSADDLE_OK) stop 2
  status = pafi%result(pout)
  if (status /= RGSADDLE_OK) stop 3
  status = pafi%profile(arcs, grad, grad_err, free_e, free_err, written)
  if (status /= RGSADDLE_OK) stop 4

  call init_ohtst_config(ocfg)
  ocfg%thermal = 0.5_c_double
  ocfg%shooting_friction = 1.5_c_double
  ocfg%shooting_shots = 4096_c_int64_t
  point = [0.0_c_double, 0.0_c_double]
  normal = [1.0_c_double, 0.0_c_double]
  status = tx%create(ocfg, 2_c_int64_t, point, normal)
  if (status /= RGSADDLE_OK) stop 5
  cb => quad_saddle
  status = tx%run(cb, c_null_ptr)
  if (status /= RGSADDLE_OK) stop 6
  status = tx%result(oout)
  if (status /= RGSADDLE_OK) stop 7
  status = tx%curve(t, kappa_t, written)
  if (status /= RGSADDLE_OK) stop 8

  write(*, '(a,1x,f8.5,1x,a,1x,f8.5)') 'barrier=', pout%barrier, 'kappa=', oout%kappa
end program pafi_ohtst_demo
#+end_src

Build and run it against the installed prefix. =-L= for the cargo library comes before the pkg-config libraries, which already include =-lrgsaddle=:

#+begin_src sh
cargo build --locked --features capi
meson setup build -Dfortran=enabled --prefix "$PWD/dist" --libdir=lib
meson install -C build
PKG_CONFIG_PATH="$PWD/dist/lib/pkgconfig:$PWD/dist/share/pkgconfig" \
  gfortran -std=f2008 -fcheck=all \
  $(pkg-config --cflags rgsaddle-fortran) \
  pafi_ohtst_demo.f90 \
  -Ltarget/debug -Wl,-rpath,"$PWD/target/debug" \
  $(pkg-config --libs rgsaddle-fortran) \
  -o pafi_ohtst_demo.x
./pafi_ohtst_demo.x
#+end_src

The full test suite in =tests/fortran/= exercises NEB, dimer, Lanczos, PAFI (1D double well and 2D widening barrier), OH-TST (aligned and tilted planes, BAOAB and GHMC), callback =user= forwarding, and nested re-entrancy.
