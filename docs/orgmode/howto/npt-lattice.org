#+TITLE: NPT lattice sampling
#+OPTIONS: toc:nil num:nil

=npt_lattice= samples the lattice parameter of a crystal under isotropic Langevin dynamics with a Berendsen barostat. It is the zero-pressure lattice that a finite-temperature calculation needs before it builds a cell, such as the copper validation in =howto/defect-pair-rates=. The module is =npt=. It holds =NptConfig=, =NptReport= and =npt_lattice=, and the first two are re-exported at the crate root.

* What the run does
The caller passes the Cartesian =positions=, the row-major =Cell=, a temperature, a mass and an evaluator. The evaluator returns =(energy, gradient, stress)= for a position and a cell, with the stress a tension-positive Cauchy stress. Energy is accepted for compatibility and unused. Units follow =BOLTZMANN_EV_PER_K= and =angular_scale_rad_s=: eV, Å and amu, with times in seconds in the configuration.

Each step is a velocity-Verlet half step, an Ornstein-Uhlenbeck thermostat step with the centre-of-mass momentum removed, the second half step, and a Berendsen rescaling of the cell and the positions by the cube root of a volume factor limited to 0.5 per cent. The pressure that drives the barostat and that the report carries is the kinetic pressure =2 K / (3 V)= minus a third of the trace of the stress. Leaving the kinetic term out would sample the cell where the configurational stress vanishes instead of the zero-pressure cell. =tests/npt_lattice.rs= checks the kinetic term against an ideal gas, which reads =(N - 1) k T / V= once the centre-of-mass momentum is removed, and against atoms tethered to cell-scaled sites, whose total pressure is zero at every volume.

* Configuration
=NptConfig= is non-exhaustive. Start from =NptConfig::default()= and chain the =with_*= setters.

| Field | Setter | Default |
|-------+--------+---------|
| =repeats= | =with_repeats= | 6, conventional cells per lattice vector, so the reported lattice parameter is the cube root of the volume over this |
| =steps= | =with_steps= | 4000, the first run length |
| =maximum_steps= | =with_maximum_steps= | 4000, the longest run after extensions |
| =extension_steps= | =with_extension_steps= | 1000, added when the pressure screen is not met |
| =equilibration_steps= | =with_equilibration_steps= | 2000, discarded before statistics |
| =block_steps= | =with_block_steps= | 250, the length of one reported block |
| =timestep_s= | =with_timestep_s= | 2e-15 |
| =langevin_gamma_per_s= | =with_langevin_gamma_per_s= | 1e12 |
| =berendsen_tau_s= | =with_berendsen_tau_s= | 0.5e-12 |
| =compressibility_per_ev_a3= | =with_compressibility_per_ev_a3= | 1 / 0.87 |
| =target_pressure_ev_a3= | =with_target_pressure_ev_a3= | 0 |
| =seed= | =with_seed= | 11 |

The call needs at least two blocks of =block_steps= in the production part of =steps=, finite positive controls, and =steps <= maximum_steps=; otherwise it returns =SaddleError::Invalid=. =block_steps= sets =NptReport::blocks=, the number of complete blocks, and that floor. It does not set the standard errors.

* The random stream
The thermostat noise is xoshiro256** (Blackman and Vigna) with its state expanded from the seed by SplitMix64, as the authors prescribe. Every seed, including consecutive ones, therefore starts an unrelated stream, and seed 0 is valid. A stream is a function of the seed alone, so a run is reproducible.

* Standard errors
Successive steps of a barostatted run are correlated over many hundreds of steps, so the plain standard error of the steps, or of block means shorter than the correlation time, is too small. =npt_lattice= blocks the per-step series instead (Flyvbjerg and Petersen, J. Chem. Phys. 91, 461 (1989), doi:10.1063/1.457480). Neighbouring pairs are averaged to double the block length, the standard error of the block means is computed at every level, and the reported value is the largest over the levels that keep at least sixteen blocks. That choice errs high: on 24 uncorrelated series of 16384 values it averaged 1.14 times the plain standard error. The estimator is tested in =src/npt.rs= on autoregressive series whose standard error is known in closed form. At a correlation parameter of 0.995 over 131072 steps the estimate averaged 1.01 times the exact value over 24 seeds, where 250-step block means averaged 0.65 times it.

A standard error is only as good as the run is long against the correlation. =lattice_error_resolved= and =pressure_error_resolved= are true when the last doubling of the block length raised the estimate by no more than its own sampling error, which is the plateau of the blocking curve, and for a series with no spread. When a flag is false the estimate was still rising at the longest block length the run allows, and the standard error is a lower bound. A run of 2000 production steps of the copper cell in =howto/defect-pair-rates= shows it: its lattice standard errors of 0.00004 to 0.00013 Å are unresolved, and eight seeds of that run scatter by 0.0006 Å.

* Reading =pressure_converged=
=NptReport::pressure_converged= is true when the pressure error is resolved and the mean pressure is within two standard errors of the target, with a series that has no spread passing only at exactly zero residual. It is indicative. It is a screen, not a proof of equilibrium: it cannot see a drift slower than the run, and a two standard error window passes a real bias about one time in twenty. Read a true as "no evidence of bias at this run length", and read a false as "run longer or look at the spread", not as a failed calculation. The lattice standard error has its own flag and is not part of the screen.

A run that fails the screen extends by =extension_steps= until it passes or reaches =maximum_steps=. With the defaults, =maximum_steps= equals =steps=, so no extension happens unless the caller raises the cap.

* Runnable example: the pressure of an ideal gas
The example is =examples/npt_lattice.rs=.

#+begin_src rust
use ndarray::Array1;
use rgsaddle::{BOLTZMANN_EV_PER_K, Cell, NptConfig, SaddleError, npt_lattice};

fn main() -> Result<(), SaddleError> {
    let per_side = 5;
    let spacing = 4.0;
    let mut positions = Vec::new();
    for i in 0..per_side {
        for j in 0..per_side {
            for k in 0..per_side {
                positions.extend([i, j, k].map(|index| index as f64 * spacing));
            }
        }
    }
    let atoms = positions.len() / 3;
    let mut positions = Array1::from_vec(positions);
    let edge = per_side as f64 * spacing;
    let mut cell = Cell([[edge, 0.0, 0.0], [0.0, edge, 0.0], [0.0, 0.0, edge]]);

    let temperature_k = 300.0;
    let config = NptConfig::default()
        .with_repeats(per_side)
        .with_steps(4_000)
        .with_maximum_steps(8_000)
        .with_extension_steps(2_000)
        .with_equilibration_steps(1_000)
        .with_compressibility_per_ev_a3(1.0e-12)
        .with_seed(3);
    let report = npt_lattice(
        &mut positions,
        &mut cell,
        temperature_k,
        63.546,
        config,
        |x, _| Ok((0.0, Array1::zeros(x.len()), [[0.0; 3]; 3])),
    )?;

    let ideal = (atoms - 1) as f64 * BOLTZMANN_EV_PER_K * temperature_k / edge.powi(3);
    println!(
        "{} steps, pressure {:.4e} +- {:.1e} eV/A^3 (resolved {}), ideal gas {ideal:.4e}",
        report.steps,
        report.mean_pressure,
        report.pressure_standard_error,
        report.pressure_error_resolved
    );
    Ok(())
}
#+end_src

It prints the pressure of 125 non-interacting atoms against =(N - 1) k T / V=. Run it with =cargo run --release --example npt_lattice=.
