#+TITLE: Recover a sparse Hessian
#+OPTIONS: toc:nil num:nil

A cutoff potential has a zero Hessian block between atoms that do not interact. ~sparse_hessian~ recovers those blocks directly. Build an atom-level ~SparsityPattern~, colour it at distance 2, and read ~SparseHessian~. The same value implements ~rgmin::ApplyHessian~. ~to_dense~ is the dense export.

The colouring is greedy in smallest-last order. Two atoms share a colour only when they are not neighbours and share no neighbour, so one gradient difference recovers every block touched by that colour. Each colour is one call to ~eval_displacements~, in colour order, with the three Cartesian probes of that colour packed together. Central differences use both sides. Forward differences use one side and a single centre evaluation. The reported evaluation count is ~n_colours * 3 * sides~, plus one for a forward centre. The displacement ~h~ is ~SparseHessianOpts::step~.

After recovery the blocks are replaced by ~(H + H^T) / 2~. The symmetric substitution method is not used. Star colouring is not used.

The pattern is symmetric and off-diagonal. The diagonal block is implied. ~from_positions~ uses linkcell's minimum image when a cell is given, and Euclidean distance when the cell is absent. Pass ~r_c~ for a pair potential, ~2 r_c~ for an atom-centred model, and ~r_c~ times the layer count for a message-passing model. A cell smaller than the cutoff does not store a self loop: a periodic image of an atom is that atom.

~lowest_eigenpairs~ runs Lanczos on ~matvec~. It does not call the surface. Inner products go through ~rgmin::vecops~. ~project_excluded~ removes the rows returned by ~PointSurface::excluded_modes~.

~one_atom_hessian~ is the one-atom displacement used as the baseline. ~prefactor_hessian~ is the compressed seed. ~Index1Config::sparse_pattern~ passes that seed to ~Index1Session~ on the first step when no Hessian was supplied. The field defaults to none, so an index-1 search that does not set it still builds a dense central-difference Hessian.

This crate sits with [[https://github.com/OmniPotentRPC][OmniPotentRPC]]. The seat that owns the ticket is [[file:../seat.org][ljos, rgmin, and rgpot]].

The partition is Curtis, Powell, and Reid, IMA J. Appl. Math. 13, 117 (1974), https://doi.org/10.1093/imamat/13.1.117. The distance-2 rule is Gebremedhin, Manne, and Pothen, SIAM Rev. 47, 629 (2005), https://doi.org/10.1137/S0036144504444711. Powell and Toint, SIAM J. Numer. Anal. 16, 1060 (1979), https://doi.org/10.1137/0716078, is the substitution method this recovery does not run.

#+begin_src rust
let pattern = SparsityPattern::from_positions(x.view(), Some(&cell), cutoff)?;
let hessian = sparse_hessian(&surface, x.view(), &pattern, SparseHessianOpts {
    difference: FiniteDifference::Central,
    step: 1e-6,
})?;
let dense = hessian.to_dense();
let (values, vectors) = hessian.lowest_eigenpairs(1)?;
let _ = (dense, values, vectors);
#+end_src
