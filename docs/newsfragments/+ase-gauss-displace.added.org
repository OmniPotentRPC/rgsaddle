~rgsaddle.ase.MinModeAtoms.displace~ follows ASE 3.29's default Gaussian displacement. With ~random_seed~ set, the ~RandomState~ normals match ASE, including a mask and a ~displacement_center~ limited by ~radius~ or ~number_of_atoms~. The default ~initial_eigenmode_method='gauss'~ takes one further draw as the mode and restores the positions. ~get_potential_energy~ stores that guess. ~get_forces~ still rotates it with this dimer.
