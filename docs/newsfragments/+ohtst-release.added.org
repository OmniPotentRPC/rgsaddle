Optimal-hyperplane transition state theory (OH-TST) sampling, plane optimization, multistate Bennett acceptance ratio (MBAR), reversible work, transmission coefficients, and rate assembly are now exposed across the Rust, C, and Python surfaces.
In Rust, =MbarConfig=, =MbarFreeEnergy=, and =mbar_free_energies= solve MBAR directly, while =OhTstRateConfig=, =ohtst_rate_with_config=, and =rate_from_parts= assemble OH-TST rates with configurable plane and temperature matching tolerances.
C ABI minor 46 adds =rgsaddle_point_fn=, =rgsaddle_ohtst_sample_config_t=, =rgsaddle_ohtst_sample_report_t=, =rgsaddle_ohtst_optimize_config_t=, =rgsaddle_ohtst_optimize_report_t=, =rgsaddle_ohtst_work_config_t=, =rgsaddle_ohtst_work_report_t=, =rgsaddle_ohtst_transmission_config_t=, =rgsaddle_ohtst_transmission_report_t=, =rgsaddle_ohtst_rate_in_t=, =rgsaddle_ohtst_rate_out_t=, =rgsaddle_ohtst_sample=, =rgsaddle_ohtst_optimize=, =rgsaddle_ohtst_mbar=, =rgsaddle_ohtst_work=, =rgsaddle_ohtst_transmission=, and =rgsaddle_ohtst_rate=.
The Python package exports =OhtstSample=, =OhtstOptimum=, =OhtstMbar=, =OhtstWork=, =OhtstTransmission=, =OhtstRate=, =ohtst_sample=, =ohtst_optimize=, =ohtst_mbar=, =ohtst_work=, =ohtst_transmission=, and =ohtst_rate=.
