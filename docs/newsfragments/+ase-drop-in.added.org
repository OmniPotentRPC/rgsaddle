Python gains ASE-shaped drivers. =rgsaddle.ase.NEB= takes a list of
Atoms with calculators, interpolates, and returns interior forces an
ASE optimizer can step. A climb skips an image whose higher endpoint
slopes into the band. =MinModeAtoms= returns the dimer or Lanczos
effective force. =Sella= runs the order-1 trust step inside ASE's
=run(fmax, steps)= loop.
The C projection is =rgsaddle_band_project= at ABI minor 35.
An unresolved energy-weighted or live Onsager-Machlup spring, a
non-finite minimum-mode start, and a two-image band now return
=SaddleError= instead of a made-up spring, a solver status, or a
session that cannot step.
