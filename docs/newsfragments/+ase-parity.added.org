~rgsaddle.ase.AutoNEB~ follows the ~ase.mep.AutoNEB~ call shape, and ~rgsaddle_autoneb_run~ is the run-to-completion C entry point behind it, added at C ABI minor 66. Its ~run()~ returns an ~AutoNEBReport~ (~status~, ~max_force~, ~ci_index~, ~surface_rows~, ~n_images~, ~iteration~, ~positions~, ~images~), so a caller can tell a converged search from one that spent its steps.
