~rgsaddle.ase.AutoNEB~ follows the ~ase.mep.AutoNEB~ call shape, and ~rgsaddle_autoneb_run~ is the run-to-completion C entry point behind it. Its ~run()~ returns an ~AutoNEBReport~ with the ~status~, ~max_force~, ~iteration~, and the finished ~images~, so a caller can tell a converged search from one that spent its steps.
