The reproducible build and test gate runs ~ci/gate/plan.json~ through ~ci/gate/run.py~ on a portable pixi leg and an EESSI leg, for x86_64 and aarch64, and writes one Markdown report per leg.
~ci/gate/plan.ncl~ is the single source of the plan and of ~.github/workflows/gate.yml~; ~pixi run check-gate~ fails when either generated file differs from it, without rewriting them.
The pixi environments ship ~capnp~ for the all-features build, the EESSI scripts keep the caller's ~PATH~, and test counts report passed, failed, ignored, and skipped totals for cargo, pytest, and Meson.
