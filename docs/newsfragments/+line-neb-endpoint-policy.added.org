=LineNebConfig::with_endpoint_below_energy= selects the endpoint policy for a running fixed-energy LI-NEB session. =EndpointBelowEnergy::Restrained= retains the published restraint and zero action weight while an endpoint is below =E=. =EndpointBelowEnergy::Strict= stops with =SaddleError::LineNebEndpointBelowEnergy=, which reports the endpoint, =V - E=, and the session step.
