The =DirectionCover= gap score now always counts the start among the states bounding a gap, as documented. A gap whose nearest tried arms reached products A and B is weighted by 3 and one reaching only A by 2, where the start was left out unless an arm had returned to it. This changes the order of the arms: on the Müller-Brown test the lower saddle is now first reached on arm 42 of the 64 cover points, so that test runs 48 arms.
