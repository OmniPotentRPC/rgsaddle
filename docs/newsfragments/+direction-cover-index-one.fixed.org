ART direction-cover climbs now retain the tracked index-1 mode by checking curvature and mode overlap, recovering the carried curvature or restarting from the last accepted mode. Exhausted recovery is reported as =SaddleError::ArtIndexOneLost= and =ArmFailure::IndexOneLost=. Per-arm force-call positions are retained in a configurable bounded window (64 calls by default), while total call counts remain available.
