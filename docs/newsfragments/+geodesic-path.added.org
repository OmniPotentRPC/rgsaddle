~geodesic_path~, ~geodesic_interpolate~, ~geodesic_lengths~, ~GeodesicConfig~, and ~MorsePairChart~ minimize the redundant coordinate path length of Zhu, Thompson, and Martinez, J. Chem. Phys. 150, 164103 (2019), doi:10.1063/1.5090303.
The chart is caller supplied. ~MorsePairChart~ is their Eq. (7) with alpha 1.7 and beta 0.01. When a ~minimage::Cell~ is set, pair distances, Cartesian midpoints, subdivision samples, and inserted images all follow the minimum image displacement, and ~rgsaddle_geodesic_path~ takes an optional cell for a host chart.
Interior images take an L-BFGS step from rgmin on the analytic length gradient. The endpoints stay fixed.
~geodesic_interpolate~ follows their Algorithm 3. The target is the average of the redundant coordinates, \((q(A) + q(B)) / 2\). Ten seeded noisy starts alternate between the reactant and the product, the middle image is adjusted on the three point path, and the images are copied onto thirds. ~GeodesicConfig::seed~ sets the noise.
The C entry points check ~n_images * dof~, ~n_coords * dof~, and the Morse pair count times ~3 * n_atoms~ with ~checked_mul~ and a slice size limit, and return ~RGSADDLE_INVALID_PARAMETER~ on overflow.
A run that uses all of ~max_sweeps~ with an image still moving is reported: ~GeodesicReport::converged~ is false, and the C entry points return ~RGSADDLE_NOT_CONVERGED~ with the last iterate in the outputs.
The C ABI adds ~rgsaddle_geodesic_config_default~, ~rgsaddle_geodesic_path~, and ~rgsaddle_geodesic_morse~.
